# Cyprus Night Pharmacies Application

Welcome to the Cyprus Night Pharmacies Application! This app is designed to help users easily find on-duty pharmacies in Cyprus. The app provides features for viewing pharmacies on a map, planning routes to them, and accessing on-duty schedules up to 10 days in advance.

## Features

- **Map View:** Easily locate on-duty pharmacies on a map.
- **Route Planning:** Get directions to the nearest on-duty pharmacy.
- **Future Schedules:** View on-duty pharmacy schedules for the next 10 days.
